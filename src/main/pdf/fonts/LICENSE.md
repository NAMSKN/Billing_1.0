# Bundled fonts

## Noto Sans (NotoSans-Regular.ttf, NotoSans-Bold.ttf)

Noto Sans is used to render the Indian Rupee sign (₹, U+20B9) on the GST tax
invoice, which the PDF standard fonts (Helvetica) cannot display.

Copyright the Noto Project Authors (https://github.com/notofonts/latin-greek-cyrillic).

The full license text is available at: https://openfontlicense.org

The fonts are embedded in generated PDFs and shipped with the application,
which the OFL permits (bundling with software, including for embedding).
